LumaBar

Control your smart bulbs from the Mac menu bar, over your own network. Works with WiZ, Tuya, Yeelight, LIFX, Hue and Home Assistant.

Built 21 Oct 2026. Tested on a real WiZ bulb; the other brands only against simulated bulbs.

SiteSnap

Take photos on site, add a note to each, and share a clean PDF report. It works offline, with no account.

Built 22 Oct 2026. Tested in desktop browsers and an automated suite; not yet on many real phones.

Open the appSource on GitHub

Brink

A thin strip of light along your Mac screen’s edges that follows the beat of your music and glows for notifications and calls.

Built 23 Oct 2026. Music reaction works on my Mac; the notification glow is experimental.

Source on GitHub

Joinbar

A Windows tray app: a countdown in the icon, reminders with a Join button, and a join shortcut.

Built 23 Oct 2026. Built on a Mac and not yet run on a Windows PC; it is a pre-release.

How a day goes.

  1. An hour

    First, pick an idea small enough to finish.

  2. Most of the day

    Then build it, start to finish, in the open.

  3. A few hours

    Then break it on purpose and fix what falls over.

  4. An hour

    Last, ship it with a README that says what is not tested.

About dailytech.build

dailytech.build is one person building one small app a day and showing all of it. Each one starts as something I wanted and could not find, or could only find behind a payment. LumaBar came first, on 21 October, for the lights on my desk. SiteSnap followed, for site engineers who need a clean report from a muddy phone. Brink and Joinbar came on the 23rd, one for the Mac and one for Windows. Everything is free and open source, and nothing needs an account. I say what I have tested and what I have not: LumaBar is proven on one real bulb, Joinbar has never run on Windows, and Brink’s notification glow is still a guess. If one fails for you, tell me.
